# Biedronka HAKY Salary — v0.7.0

## Новое
- Нижняя мобильная навигация.
- Выбор месяца.
- Доход за календарный месяц.
- Окно выплаты показывается отдельно: 20-е — последний день месяца.
- История смен и календарь.
- Редактирование и удаление смен.
- Предварительный расчёт: картоны / почасовая / жильё.
- Статистика по отделам.
- Лучший день, средняя смена, остаток до цели.
- Multi-User и Supabase RLS сохранены.
- Исторические ставки смен сохраняются в rates_snapshot.

## Обновление
Новый SQL выполнять не нужно. Достаточно обновить файлы через Git и дождаться автоматического деплоя Vercel.
