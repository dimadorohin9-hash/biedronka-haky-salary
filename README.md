# Biedronka HAKY Salary — v0.5.0 Cloud

Это первая облачная версия. Данные больше не обязаны жить только в одном браузере.

## Что уже есть

- Supabase Auth: регистрация и вход по email + паролю.
- Облачная таблица смен.
- Облачные настройки коэффициентов и цели.
- Row Level Security: каждый аккаунт видит только свои данные.
- Исторический snapshot ставок в каждой смене.
- Синхронизация: после входа с другого устройства загружаются те же смены.
- Добавление и удаление смен.
- Текущие коэффициенты:
  - P01 0.1908
  - P02 0.1595
  - P03 0.133
  - P21 0.1867
  - P28 0.1631
  - часовая ставка 33.66 zł
  - жильё +2.00 zł/час

## 1. Создай Supabase

1. Создай новый проект Supabase.
2. Открой SQL Editor.
3. Скопируй содержимое `supabase/schema.sql` и выполни его.
4. В Supabase открой Connect / API и скопируй:
   - Project URL
   - Publishable key

## 2. Подготовь проект

В папке проекта создай `.env.local` на основе `.env.example`:

NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=...

## 3. Установи Node.js

Нужен современный Node.js (LTS).

Затем в терминале в папке проекта:

npm install
npm run dev

Открой:
http://localhost:3000

## 4. Создай аккаунт

На странице входа введи email и пароль и нажми «Создать аккаунт».
Если в Supabase включено подтверждение email — подтверди письмо.
