# Biedronka HAKY Salary — v0.8.0

Новое:
- Архив зарплат по месяцам.
- Экспорт выбранного месяца в CSV, который открывается в Excel.
- Печать / сохранение отчёта в PDF через системный диалог браузера.
- PWA manifest: сайт можно добавлять на домашний экран как приложение.
- Сохранён Multi-User и RLS.
- Включён исправленный `user_id` при сохранении личных ставок.
- Исторические ставки смен по-прежнему берутся из `rates_snapshot`.

Новый SQL для Supabase не нужен.
